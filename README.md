# Fluent11 ISO Studio

Personalize uma imagem do Windows 11 com uma interface nativa em **WinUI 3**, em português do Brasil.

- **Equilibrado:** reduz aplicativos e componentes, mantendo atualizações, recuperação e Defender.
- **Mínimo:** reduz mais componentes e remove suporte a manutenção e recuperação. Apenas para máquinas virtuais de teste.
- **Personalizado:** permite escolher o que remover ou manter.

Extraia todo o pacote e execute `Fluent11ISOStudio.exe` como administrador.

[Instruções em português](docs/pt-BR.md) · [Avisos de atribuição e distribuição](NOTICE.md)

Teste a ISO em uma máquina virtual antes de instalar o Windows.
